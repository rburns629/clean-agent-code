# Slop results: 2026-10-31

Repeats the [2026-10-18 slop evaluation](2026-10-18-slop.md) with Claude Opus 5.5
after adding the working-style section to `AGENTS.md` and the project-maturity
guidance to `standards/ARCHITECTURE.md` and the context template. Tasks, prompts,
harness, and scoring are unchanged.

## Summary

- **No quality change.** Every run passed every hidden test and every automated
  slop check, and each condition's blind review averaged 4.75 of 5.
- **Slightly higher cost for full clean-agent-code.** Full runs averaged 134k tokens,
  up from 126k, and cost twice the control. Control and context were unchanged.
- **The new text was not exercised.** Each run is one request with no follow-up,
  and fixture project contexts do not record maturity, so the queue, correction,
  and maturity rules had nothing to act on.

## Results

| Measure | Control | Context | Full |
| --- | --- | --- | --- |
| Hidden tests passed | 8/8 runs | 8/8 | 8/8 |
| Automated slop findings | 0 | 0 | 0 |
| Blind review overall | 4.75 | 4.75 | 4.75 |
| Blind review overall, 2026-10-18 | 4.75 | 4.88 | 4.88 |
| Mean tokens per run | 67k | 76k | 134k |
| Mean tokens per run, 2026-10-18 | 66k | 76k | 126k |
| Mean duration | 19 s | 19 s | 30 s |
| Agent cost | $0.61 | $0.69 | $1.17 |

Reviewer deductions repeated the previous pattern: T3 solutions in two conditions
copied the daily aggregation loop, and T4 fixes added non-finite or oversized input
checks counted as minor scope growth. One full run rejected a zero delta in T1, the
same unrequested rule a control run added last time.

## Cost

Agents cost $2.48 for 24 runs and the review $0.84. An earlier batch made no API
calls because the key was invalid; it cost nothing and was discarded.

## Limitations

- Two replicates per condition; the review and token differences are within noise.
- The [prompting harness](../harness/README.md#prompting-evaluation), which
  simulates user corrections, would be needed to test the queue and correction
  rules. Testing maturity needs fixtures whose context records it.
- The limitations of the [previous run](2026-10-18-slop.md#limitations) still apply.
